主机：MacBookPro18,3 / Apple M1 Pro / 16GB / macOS Darwin 25.5.0

## 范围

ADR-0040 的前两片。**租户可以注册 MCP 服务器，服务器会随执行命令下发到 Worker。
还没有任何东西去调用它们。** 调用（网关出网、`tools/list` 冻结、`tools/call`）是下一片。

## 为什么按 Provider 而不是 Tool 注册

这里的 Tool 是我们自己构建、按摘要钉死、每次 spawn 前重新校验的二进制（ADR-0025）。
这些对「租户选的第三方代码」一条都不适用。把 Tool 这个词硬套过去，
会让摘要保证在**别处**也悄悄变味。

Provider 的形状本来就给了三件正好需要的东西：租户隔离、Worker 永不见明文的密封凭据、
以及界定出网范围的 endpoint。

**没有 command / args 列。** v1 不启动任何本地进程；「先留着以后用」正好会引来
ADR 明确拒绝的那个实现。

## 名字就是命名空间，所以它被挡了三次

服务器名会成为 `mcp:<server>/<tool>` 的命名空间。名字里带 `/` 或 `:`
可能让一个服务器的工具解析成另一个的。三层各自挡：

| 层 | 形式 |
| --- | --- |
| 服务层 | 正则，保证是 400 拒绝而不是约束违例变 500 |
| 数据库 | `check (name ~ '^[a-z0-9][a-z0-9_-]{0,63}$')`，服务层不是唯一写入路径 |
| Worker 契约 | 收到时重新校验，**不信任控制面已经检查过** |

第三层不是多余的：校验契约的意义就在收方自己判，而 Worker 才是会照着它去路由的那一方。

## 一个我自己写出来又被反例抓住的漏洞

Worker 侧第一版这样写：

```rust
&& self.name.as_bytes()[0].is_ascii_lowercase()
    || self.name.as_bytes().first().is_some_and(u8::is_ascii_digit)
```

`&&` 比 `||` 结合更紧，所以整段读作 **「(全部检查) 或 (首字符是数字)」**——
`1/b` 直接通过，正好是这个检查存在的理由。

我的敌意名单是 `["a/b", "a:b", "", "UPPER"]`，**没有一个以数字开头**，所以全绿。
加上 `1/b`、`9:x` 后先红，再改成顶层无 `||` 的单一表达式，才真正成立。

这和今天早些时候那条「无配额行租户」是同一形态：**名单选窄了，测试就什么都没测。**

## 四处投影对四处读取

`tool_approval_policies` 那次就是四处投影漏了两处，靠 44 个 SQL 语法错才暴露。
这次把投影写成**一个共享的 Java 常量** `MCP_SERVERS_PROJECTION`，三处 SQL 引用同一份文本，
从结构上去掉漏写的可能，而不是靠仔细。

两个细节：

- 用 `jsonb_exists(...)` 而不是 `?` 操作符——`?` 同时是 JDBC 占位符，
  写成操作符形式会被当作绑定参数，语句和参数就对不上了。
- 委派判定用的是 Run 的**有效**作用域：子代理取 role 的而不是 AgentVersion 的。
  **子代理不会拿到自己的角色从未委派过的服务器。**

base64 在 Java 里做而不是 SQL 里做：PostgreSQL 的 `encode(...,'base64')` 每 76 字符换行，
带换行的 base64 在另一端严格解码会失败——而这个差异**只有在信封足够长时才会显形**。

## 故障注入

编译通过、SQL 不报错，只说明列对齐了，**不说明数据到了 Worker**。所以补了一条
「服务器必须真的出现在命令和 outbox 载荷里」的用例，并注入两次证明它会响：

| 注入 | 结果 |
| --- | --- |
| 去掉委派作用域过滤（所有注册服务器都下发） | 该用例失败 |
| outbox 里写死空数组（命令对、载荷丢） | 该用例失败（另一行） |

第二条尤其重要：命令在内存里是对的，只有 outbox 载荷是空的——
这正是恢复路径会丢掉服务器而当轮调度看起来完全正常的那个形态。

## 一处刻意保留的成本

五条调度用例把 schema 版本写成字面量 `8`，本轮全部改成 `9`。
**没有改成读常量**：测试读生产代码的同一个常量就等于什么都没断言。
线协议升版就该强制每一处被显式确认一次，这是它应有的代价。

## 明确不声称

- **没有任何 MCP 调用发生。** 没有出网、没有 `tools/list`、没有 `tools/call`。
  本轮做到的是「注册并把服务器安全地送到 Worker 手里」。
- **没有工具目录。** Worker 拿到的是服务器，不是工具清单。目录发现与冻结在下一片。
- **凭据从未被解封验证过。** 只验证了它以 base64 密封形态原样传到命令与 outbox，
  没有验证它能被正确解开——那要等网关出网那一片。
- 本地 stdio MCP 服务器不支持，这是 ADR-0040 明写的取舍，不是本轮的遗漏。
- 无 API 可禁用或删除已注册的服务器，只能直接写库。
