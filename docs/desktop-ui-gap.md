# 桌面客户端能力清单（对标 Codex / OpenClaw）

- 日期：2026-08-18
- 范围：`desktop/`。**不含** Runtime 内核；内核缺口见 `docs/roadmap.md`

## 当前目标：可日用的 macOS Desktop Alpha

本清单不再等待所有内核能力完成后才启动。当前优先形成一条真实纵向闭环：应用启动并恢复 Runtime，
安全配置 Profile/credential，创建或继续 Session，流式显示事件，完成 Tool 审批/拒绝/取消，查看历史并
进行基础 Workspace 交互，最后随应用退出完全停止 Runtime。现有 Electron + React 实现继续使用；
renderer 不拥有凭证、owner token 或另一套 Agent 状态机。

命令面板、子代理树、PTY、MCP 浏览器和复杂 Diff 审阅仍保留在对标清单，但不阻塞 Alpha；Profile/credential、
真实 Session 主链和干净目录可分发验收是硬门禁。

状态取值：`未做` / `待接入`（界面在、数据未接） / `已接入`

## 一、Codex / Claude Code 有而我们没有的

这些是终端形态的编码客户端已经证明必要的交互，不是猜测。

| # | 能力 | 状态 | 备注 |
| --- | --- | --- | --- |
| 1 | 命令面板（⌘K） | 已接入 | 命令由各面自己注册（`commands()`），面板只把它们列出来并执行 —— 新功能落在自己的面上就自动出现在这里，不必在两处登记。**没有** `/` 前缀那一套 |
| 2 | 文件引用（`@` 提及） | 部分接入 | `@` 从**工作区自己**的列表补全（和工作区面读的是同一个调用），所以进消息的路径是 Runtime 会接受的那个，而不是记忆里的那个。词中间的 `@` 不触发（那是邮箱、装饰器、handle）；列表开着时 Enter 归它，否则半个提及会被发出去。走的是**整个工作区**（有界的遍历：深度 4、2000 个文件、400 个目录），所以 `@main` 找得到 `src/main.rs`，进消息的是从根算起的完整路径；走不完时**说出来**，而不是让它看起来像文件不存在。**还没有**：拖放、粘贴图片 |
| 3 | 计划模式 / 权限模式切换 | 未做 | Codex 与 CC 都把它放在状态行常驻 |
| 4 | 运行中的待办清单 | 未做 | 模型自己维护的任务列表，实时渲染 |
| 5 | 推理过程显示 | 已接入 | `model.reasoning` 的 `summary` 是 `Vec<String>`，客户端按字符串读，正文一直被静默丢掉——只剩一条发丝线。现在按列表渲染，每段一行；同一处改动让这段散文进了 `Mark`，⌘F 原来到不了它。**流式思考已接入**：会边想边说的 Provider（vLLM 服务的 Qwen3 发 `delta.reasoning`，DeepSeek 与 vLLM/SGLang 的 parser 发 `delta.reasoning_content`）此前**整段被丢掉**——真机上一句话的问题思考量是回答的 6 倍，屏幕却是空的。现在走 `model.reasoning.delta`，转录里画成单独一块（比回答更轻），状态行说「在想」。**不进冻结转录**：要不要回传给模型是耐久格式决定 |
| 6 | Diff 逐块接受 / 拒绝 | 部分接入 | 审批一次 `workspace.write_text` 就是审批一次覆写，而卡片此前只显示整段新内容，不显示它和文件现状的差别 —— 那个人被问的唯一问题得去另一个面上凭记忆回答。现在转录和待决定队列**两处**都画出逐行对比（同一个组件），文件读不到就说是新文件还是打不开，太大就明说不比。**拒绝现在可以带一句话**（可不填），它作为这次工具调用的结果交给模型，并且不管填不填都附上「不许绕过这次拒绝」的约束——只说「被拒绝了」读起来像一次暂时的失败，最省事的下一步就是换一扇门做同一件事。**Codex 在这里是反对的**：它的客户端决定枚举里 `Decline` 是裸变体，app-server 塞固定常量，自由文本只留给 hook/guardian。理由和不同意的理由都在对比文档里。**还没有**：逐块接受/拒绝（我们没有结构化 diff，写入是整文件替换）。**读过源码之后补一条**：这份对比是**这个窗口自己的文件系统**读的，它等于 Runtime 要写的那个文件，靠的是「Runtime 就在这台机器上」这个部署事实，不是这张卡片的性质。Codex 的做法是 worker 端算好 `unified_diff` 放进 item 里发出来，客户端一个文件都不读——换成非本机 worker 时该改成那样 |
| 7 | 运行中排队输入 | 已接入 | 跑着时 ↵ 不再改向而是**排队**，改向让给 ⌘↵ 和框边的按钮 —— 一轮里打的字最常见的是「下一句话」，而不是「改这一轮」，而原来说下一句话的唯一方式是改掉上一句的指令。一轮**干净结束**才抽一条发出去，**一次一条**（codex 与 opencode 都是一条一条，因为一个分支同时只容一轮）。取消、失败、判不了、以及「这一轮这个窗口根本没看见它跑过」，都把排着的话**放回输入框**并说出原因 —— 不确定是把话还回去的理由，绝不是发出去的理由；codex 为这件事写了整个 `input_restore.rs`。队列是**这个窗口的客户端队列**，不进内核：排着的话从来没有发给过模型，所以它不是内核状态、不进任何转录，性质上是还没发出去的草稿（codex 也是这么定位的）；内核的 `SteeringMailbox` 是槽不是队列（那是它的语义），把排队建在它上面会静默丢句子。代价说清：**不跨窗口、关窗即失**；换到别的对话也会把话放回输入框，而不是发进一段它不是写给的对话。上限 10 句，满了**拒绝并把那句留在框里**，不做 openclaw 的 summarize —— 那是别人写的、还没发出去的话，替他概括等于替他说话。**还没做**：一轮在两次轮询之间跑完又结束时抽不了干（队列原样留在屏幕上，下一轮结束时接着走） |
| 8 | 中途改向（steer） | 已接入 | 轮次在跑时同一个框能改向，但**不再是 ↵ 干的事**（↵ 归排队，见第 7 行）：改向在 ⌘↵ 和框边那个安静的按钮上，因为它动的是已经在跑的活儿，值得被明确挑一次。只在两次工具调用之间生效，界面说明了这一点 |
| 9 | 转录搜索（⌘F） | 已接入 | marks 就是计数本身；折叠里有命中会自动展开，否则计数会包含看不见的行 |
| 9.3 | 实时计时与「正在做什么」 | 已接入 | 从首个事件计时；活动短语逐条对应事件类型，**不估算进度**；不认识的事件显示原始类型 |
| 9.4 | 工具调用折叠 | 已接入 | 连续调用折成一行，行上按工具计数；单次调用不折。展开后每次调用带着**它自己的回答**——`shell.exec` 的 stdout / stderr / 退出码，读写文件的内容与字节数，MCP 工具按协议规定的 `content` 数组（画不了的部分点名而不是丢掉），截断也说出来。成功的结果折进它回答的那次调用，所以折叠仍然成立，而输出不再只存在于原始事件抽屉里 |
| 9.5 | 流式转录 | 已接入 | 主进程持连接推送，事件即写即到；边界仍只来自 cursor |
| 10 | 模型快速切换 | 部分接入 | 设置里可增删 Provider，改完点「重启 Runtime」即生效——重启的是 Runtime 不是应用，drain 报告说清打断了几个 Run；对不是本应用启动的 Runtime 会**说不能**而不是假装。仍**没有会话级切换** |
| 11 | 命令历史（↑） | 已接入 | 空行或未改动的行才回溯，不吃光标移动 |
| 12 | 多行输入与编辑键位 | 已接入 | ↵ 发送、⇧↵ 换行 |
| 13 | 原生通知 | 已接入 | 窗口不在前台时才发；每个等待项按耐久 key 去重（approval id / MCP input id+版本 / Run id），点一下把那个 Run 放到面前 |
| 14 | 会话恢复 / 继续 | 已接入 | 会话面按 `(session_id, branch_id)` 升序列出所有分支头，选一行即切过去。**重启打断一轮之后**：两个真实进程的验收证明对话接得上，恢复会放开分支，窗口约 100ms（`restart_during_a_turn.rs`）。窗口里被拒时，打的字会**放回输入框**，说的是人话不是 Runtime 的内部字符串 |
| 15 | 键位速查 | **已接入** | ⌘/ 打开。整页从 registry 的 `keys:`、`commands()` 和外壳自己的 `SHELL_KEYS` 生成，没有手写清单 |
| 16 | 导出 / 分享转录 | 部分接入 | 命令面板「复制这段对话」把**屏幕上这段**对话作为 Markdown 放进剪贴板——不是「最近那段」,剪贴板不会告诉人它从哪来。用的是转录渲染用的同一个 `textOf`,所以文件和屏幕说的不会不一样;非文本部分(工具调用、工具结果、推理摘要)不导出,理由和 `textOf` 不渲染它们是同一条。**两种不完整都写在文件顶部**:客户端翻页没取全(`turns.length < turnCount`)、以及还有一轮在跑还没落成 Turn。**还没有**:存成文件(需要 Electron 的保存对话框,目前一个都没有)、分享 |

## 二、OpenClaw 有而我们没有的

| # | 能力 | 状态 | 备注 |
| --- | --- | --- | --- |
| 17 | 节点 / 设备列表 | 未做 | 多 Runtime 时的切换与健康 |
| 18 | 连接生命周期可视 | **已接入** | 断线、重连、从哪个序号续上 |
| 19 | 离线任务队列 | 未做 | Edge 方向暂停，UI 先不做 |
| 20 | 模型容灾可视 | 部分接入 | Provider 失败与重试说得出**是哪一个、为什么、等多久、第几次**：八种 `ModelErrorKind` 各有自己的话，不认识的原样打印。**换 Provider 也说出来了**：`failed_provider_ids` 非空才画，顺利那次仍然静默——「换成了 X 来答，因为 Y 没答应」。**补上了 Provider 答的 HTTP 状态**：一个 429 现在是两种 kind（`RateLimited` 是等，`Billing` 是去付钱，且**不重试但会转到下一个 Provider**），分类说的是内核的判断，状态码才是能拿去和 Provider 自己的面板对上的那个东西——它一直在 payload 里没被画。`Option<u16>`，没有就不说，且只认数字（fixture 往这个键里塞过 run status，「HTTP running」比不说更糟）。**「第 N 次」现在说清是「第 N 次试这个 Provider」**：它是 `same_provider_attempts + 1`，在一列换 Provider 的行里读成「第 N 个 Provider」是另一件事。**退避的等待现在在状态行上**：这是唯一一个「短语算不出来、要看 payload 和时间戳」的事件——转录那行是日志、该冻住，状态行是活的，而它此前对这个事件根本没有说法，一个停在 30 秒退避上的 Run 在状态行上打的是事件类型原文。现在是「在等重试・还要 N 秒」，deadline 过了就只剩短语（`retryWait`，倒计时随 store 每 1.2s 的重读走，和旁边那个钟一样最多差一拍）。**还没有**：route journal 本身的入口；以及**失败事件里没有 Provider 的原话**——`message` 只到 `run.failed`（`provider_failure_sentence`），转移成功的那次，Provider 说了什么在客户端任何地方都看不到，这要内核把它放进 `model.provider.failed` 才有得画 |
| 21 | Workspace 冲突处理 | **已接入（Runtime 侧）** | 读过再写时，执行器把它读到的那份内容的摘要交给工具，工具在落盘前比对——文件在审批卡摆着的这段时间被改过就拒绝，手改的内容留着。一个 Run 的读不约束另一个 Run；同一个 Run 连写两次不算和自己冲突。模型不用改，因为让模型自己带摘要就等于让不自觉的模型绕过它。**还没有**：界面上把这次拒绝讲清楚（现在只是一条工具错误），以及 patch/apply（那是省 token 的事，不再是安全的事） |
| 21.1 | 选择工作目录 | **已接入** | 此前工作目录**只能靠环境变量设**，否则落在应用自己的数据目录里——装好双击打开的人，agent 干活的地方不是他的项目，而且窗口里没有任何办法改。现在工作区面上有系统目录选择器；选择被持久化，但**环境变量仍然优先**（开发用 checkout 不会被悄悄改掉），且明说要重启 Runtime 才生效 |

| 27 | 事件游标 / 原始事件检查器 | 已接入 | ⌘I 在对话面开原始事件；游标的 gap 与分页上限是两件不同的事，都各自说出来 |

| 32 | 对话渲染（Markdown） | **已接入** | 解析器是 `marked`——本机两个在卖的产品都用它（Claude Desktop 的 asar 里只有 marked；ChatGPT 的是 marked + katex + shiki），两家都没用 remark/react-markdown。**不用 `marked.parse()`**：那返回 HTML 字符串，把模型输出经 `dangerouslySetInnerHTML` 送进 DOM 就是把每条回复变成注入面；改走 `marked.lexer()` 拿 token 树自建 React 元素，不插原始 HTML，文本叶子仍过 `Mark` 所以 ⌘F 计数不变。覆盖：标题、围栏（带语言标签）、表格（含每列对齐、自己横向滚动）、嵌套列表、任务清单（只读勾选框）、引用、行内代码（含双反引号形式）、粗体/斜体/删除线、链接与裸链接（`javascript:` 不给点）、图片只画引用不发请求、转义字符、硬换行。流式残缺块按 streamdown 的分工处理：补闭合符只管行内，围栏和表格靠分块——写了一半的表格、没闭合的围栏、没写完的链接都各有守卫 |
| 33 | 会话列表 | **已接入** | 原来是四列表格，按轮次和时间排版。现在一行是：第一句（单行截断）+ 末次回复摘要（`plain()` 去掉 markdown 标记，整段是代码时如实不显示）+ 元信息（轮次或「这轮还在跑」、回滚代数、分支 id）。选中即打开这一条没变；j/k/Enter 没变 |

| MCP 服务的密钥 | provider 的密钥能进钥匙串，是因为路由配置里写的是 `api_key_env` 这个变量名。stdio MCP 的 `env` 是字面值，只能写进配置文件，所以设置里不收密钥。要解除，得给 `LocalMcpTransportConfig::Stdio` 加一个同形状的间接层 —— 那会改动 stdio 的 authority digest，是一次单独的决定 |

## 五、推进顺序

1. ~~**Owner 主链与生命周期**~~ ✅ 已完成。Electron 主进程可驱动 owner socket、恢复与退出；renderer
   不持有 socket、channel 或 token。
2. ~~**Node gRPC 客户端**~~ ✅ 已完成。`@grpc/grpc-js` + `@grpc/proto-loader` 直接加载
   `contracts/proto/runtime.proto`——Rust runtime 编译的同一份文件。**契约现由两种语言各自生成，
   "协议中立"从声称变为事实。** 连接只在主进程；preload 暴露五个方法；渲染进程没有 channel、
   没有 stream、也拿不到 token。非回环地址无 mTLS 直接拒绝，但窗口仍会打开——好过一个直接退出的进程
3. ~~**Profile / credential**~~ ✅ 密钥进登录钥匙串，配置文件只留环境变量名；桥接上不存在能取回密钥的调用。
   **仍缺**：workspace 目录选择器（现在是 `<userData>/workspace` 默认值）、改配置后自动重启 Runtime
4. ~~**真实 Session 闭环**~~ ✅ 创建/继续、Turn 级转录、会话列表与切换、审批/拒绝/取消、
   基础 Workspace 交互（目录、文件预览、代理动过的路径）全部接真数据
5. ~~**干净分发验收**~~ ✅ `Runtime Desk.app` 复制到别处、全新 userData、清空环境后完成
   「首启无 Provider → 配置 → 启动 Runtime → 跑通一轮 → 退出无残留」。**仍未签名**
6. **Alpha 后对标交互**：命令面板、文件引用、diff 审阅、待办清单、排队输入、子代理树和 PTY
7. **steer**：需先在 Runtime 侧补 `RuntimeControlAction`
